# Data Dictionary

All records in this file are fictional and created for portfolio practice.

| Field | Definition | Example / expected values |
|---|---|---|
| participant_id | Synthetic record identifier | P0001 |
| province | Province assigned to the fictional workshop | Gauteng, KwaZulu-Natal, Limpopo |
| workshop_id | Synthetic workshop identifier | W01 |
| workshop_date | Date of fictional workshop | YYYY-MM-DD |
| eligible_for_follow_up | Whether the fictional record is included in the follow-up group | Yes / No |
| follow_up_completed | Whether a follow-up response is recorded | Yes / No |
| pre_score | Fictional knowledge score before workshop | Integer from 0 to 10; may be blank |
| post_score | Fictional knowledge score after workshop | Integer from 0 to 10; may be blank |
| data_quality_note | Fictional note for checking records | None / Missing post score / Review category |
